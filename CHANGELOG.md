# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [5.7.0-Unified-Alpha] - 2026-02-10
### Added
- Unified Dashboard hub connecting all modes.
- Economy Backend (`EconomyManager`) with Marketplace support.
- Gym Mode and Workout generation logic.
- Mission Manager for persistent objectives.
- Replay Manager for input recording.
- P2P Content Swarm stubs.
- Initial VR hooks.

### Changed
- Refactored `StepMania.cpp` to initialize all new Managers.
- Updated documentation: `VISION.md`, `MEMORY.md`, `DEPLOY.md`, `IDEAS.md`.
- Sourced versioning from `VERSION.md`.

### Fixed
- Fixed submodule mappings for Simply Love and Bobcoin.
- Standardized logging across all new modules.
