# bobmania

Robert Pelloni's fork of **StepMania**, the open-source rhythm game engine — part of his dance-game workbench alongside his ITGmania fork (`robertpelloni/itgmania`), the Fitness Center Dance Machine (`robertpelloni/fcdm`), and Simply Love.

The tree contains the StepMania engine source plus development/workspace state tracked by his automation (bulk "Protocol" commits, October 2026). There is no bobmania-specific build documentation yet — for building, follow upstream StepMania's docs ([github.com/stepmania/stepmania](https://github.com/stepmania/stepmania)); expect this copy's value to be its local modifications and state, not a packaged release.
